# Food-Automation-using-n8n
This project served as one of the major hands-on learning experiences  under the Agentic AI and Automation track and provided practical exposure to intelligent workflow  orchestration, AI-assisted automation, API integration, and real-time data handling.

The primary objective of the project was to simulate a real-world automated food ordering and management system capable of handling customer interactions, processing orders, verifying inventory availability, and storing customer details automatically without manual intervention. The project demonstrated how modern automation platforms combined with Artificial Intelligence can streamline business operations and improve workflow efficiency. 

Understood the core building blocks of n8n workflows including: 
  ○ Trigger nodes 
  ○ Action nodes 
  ○ AI agent nodes 
  ○ Conditional nodes 
  ○ Data transformation nodes 
  ○ Integration nodes
